# Scene QA v3 最终结果分析

评测集为 Waymo val，共 17,490 条 QA。正式 LoRA 权重为 epoch 1 的 `best.pt`；epoch 2/3 的 val loss 更高，不作为正式结果。模型输入只有按 A–E 排列的 288 维 Grounding token 和无坐标、无 caption 的通用问题。

LoRA 相对 Projector 的严格语言合取提高 6.92 个百分点，说明 LoRA 有效。正确 token 相对同类别打乱 token 提高 17.65 个百分点，说明模型确实使用了 Grounding token，而不是只靠问题模板作答。

## 2. 具体题型诊断

| 题型 | Projector | LoRA | 打乱 token | 正确 token 增益 | 判断 |
|---|---:|---:|---:|---:|---|
| 距 ego 的距离排序 | 82.56% | 92.15% | 42.69% | +49.46 pp | token 证据很强 |
| 两物体方向关系 | 27.81% | 36.54% | 14.19% | +22.35 pp | token 有效，绝对值仍低 |
| 多参照方向关系 | 3.69% | 15.68% | 2.22% | +13.46 pp | 已学到一些，仍是难点 |
| 以目标为参照找最近/最远 | 50.53% | 60.88% | 49.22% | +11.66 pp | token 有贡献 |
| 局部避障规划 | 29.17% | 34.90% | 20.83% | +14.06 pp | token 有贡献，能力偏低 |
| 是否距 ego 10 米内 | 93.31% | 95.01% | 95.22% | -0.22 pp | 标签失衡，不能证明推理 |
| 候选动作是否安全 | 87.11% | 87.11% | 87.11% | 0.00 pp | 标签失衡，模型可忽略 token |

两个高分题型存在明确的数据偏置：

- “是否距 ego 10 米内”中，绝大多数答案是“超过 10 米”，打乱 token 仍有 95.22%。
- “候选动作是否安全”中，2,304 条 val 有 2,007 条为 safe，占 87.11%；三种模型正好都得到 87.11%。

因此，距离类 83.58% 和避障类 74.06% 不能直接作为完整空间推理能力。当前最可信的核心指标是方位类严格准确率 32.60%、两物体关系 36.54%、多参照关系 15.68% 和局部规划 34.90%。

## 3. 目标数量

| 目标数 | LoRA | 打乱 token | token 增益 |
|---:|---:|---:|---:|
| 2 | 70.80% | 54.04% | +16.77 pp |
| 3 | 61.06% | 39.19% | +21.87 pp |
| 4 | 43.67% | 32.96% | +10.71 pp |
| 5 | 41.71% | 40.00% | +1.71 pp |

N=3 的 token 增益最大，证明三目标输入已经产生有效监督。N=4 仍有一定 token 贡献。N=5 的 41.71% 主要来自题型和标签先验：Grounding 的 N=5 JointAll Acc@0.25 为 0%，正确 token 相对打乱只提高 1.71 个百分点，因此不能宣称五目标端到端能力已经建立。

## 4. Grounding 与端到端瓶颈

平衡 Grounding 的 epoch-15 checkpoint：JointAll Acc@0.25 为 55.93%；N2/N3/N4/N5 分别为 60.41%/38.68%/4.35%/0%。N2–N4 宏平均只比自然分布 baseline 高约 0.49 个百分点。

17,490 条 QA 中只有 7,658 条满足该题所需全部目标 IoU≥0.25，覆盖率为 43.79%。在这些 Grounding 正确样本上，LoRA 严格准确率为 68.73%；把 Grounding 错误一起计算后，端到端严格准确率降为 30.09%。当前完整系统的首要瓶颈仍是多目标 Grounding，尤其是 N=4/5。

- LoRA 的最佳 val loss也在 epoch 1：0.7691；epoch 2/3 为 0.9208/0.8225，已经出现过拟合。
- 正式 checkpoint 为 `runs/scene_qa_v3_pairwise_lora/best.pt`。

- 后来单独发起的 `last.pt` 评测只记录到 `GENERATE val 17490`，未生成 `eval_val.json`，不纳入结果。

## 6. 下一轮修改优先级

1. 重做两个失衡题型：分别对 within/farther 和 safe/unsafe 做按标签、动作和目标数联合平衡。
2. 将局部规划和候选安全判断分别报告，避免容易的 safe 判断掩盖真实规划能力。
3. 优先增加真实 N=3/4 场景，而不是继续复制同场景问法；N=5 需要新的独立 sequence 才能做可靠训练与验证。
4. 多目标 Grounding 优先解决 N=4/5 联合定位，QA 后端再继续优化多参照关系和 A/B 交换一致性。
5. 后续主表同时保留正确 token、同类别打乱 token、无 token/均值 token 三个对照，并单列每个具体题型。

完整机器可读统计见 `final_metrics_analysis.json`。
