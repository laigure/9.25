# 3EED 正式多目标实验口径核查

## 结论

论文 Table 3 的结果是正式 multi-object grounding 结果。作者将一条查询中所有被指物体都定位正确，才计为该查询的 Acc@0.25 / Acc@0.5 正确。论文报告 Ours 的总体结果为 Acc@0.25 32.32%、Acc@0.5 29.89%、mIoU 56.40%。

项目此前得到的 5.79% 不是这张表的复现结果。该实验使用从公开单目标标注自动拼接的自制多目标训练集、908 条训练样本、公开单目标 checkpoint 和短轮次微调。它只能说明当前自制方案表现差，不能说明 3EED 官方多目标模型只有 5.79%。

## 三种数据不能混为一谈

### 1. 公开默认单目标数据

`meta_info.json -> ground_info[]` 中的每个元素包含一条表达和一个目标框。默认 loader 逐元素展开，所以同一帧可产生多条单目标样本。

### 2. 论文正式多目标数据

一条语言查询同时描述多个被指目标，并配有多个目标框。代码中的 multi loader 读取 `waymo_multi_{train,val}_info.pkl`，并寻找 `bbox3d_obj_1`、`bbox3d_obj_2` 等字段。

### 3. 本项目自制多目标数据

将若干独立单目标中性描述拼成 `Object A ... Object B ...`，标注框来自公开单目标记录。这不是论文正式多目标标注，语言分布、样本规模、目标组合和训练配置均不同。

## 当前缺口

当前公开原始数据包和本地主机中未发现论文正式 multi-object 的 pkl 标注，因此尚不能严格复现 Table 3。下一步应先取得正式 multi 标注或按照论文补充材料准确复建它，再按官方 `scripts_multi` 训练和评估。

## 对项目决策的影响

- 保留自制数据与模型，标为“多目标管线原型”，不再称为官方多目标复现。
- 先用 50 条原始样例核实框、表达和默认 loader 的关系。
- 正式多目标数据明确前，不用 5.79% 判断模型架构能否完成多目标定位。
- QA 后端仍可先接单目标正确 token 做受控测试；多目标联合 token 必须等待正式 multi 模型复现或建立经过验证的新多目标标注方案。
